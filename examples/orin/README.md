# Example: Orin wallpaper + holdout (1200x1920)

- `wallpaper-1200x1920.png` — a portrait wallpaper: Orin (Rin Kaenbyou) on a circuit-board background.
- `holdout-1200x1920.png` — its mask: alpha > 0 where the character is, with a soft edge.

Use: put both in one folder, set the wallpaper on a 1200x1920 monitor in XFCE, and the dashboard
finds the mask by itself (`holdout-<W>x<H>.png` next to the wallpaper).
